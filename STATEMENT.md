College Event Management System

# 1. Problem Statement

Colleges organize various events such as technical competitions, cultural programs, workshops, seminars, and other student activities. Managing event details and student registrations manually can be difficult and time-consuming.

The **College Event Management System** is a Python-based application designed to provide a simple and organized way to manage college events and student registrations. The system allows the user to add events, view available events, register students for events, and view registration details.

The project aims to apply Python programming concepts to solve a practical college event management problem.

---

## 2. Scope of the Project

The scope of this project includes basic management of college events and student registrations.

The system provides the following functionality:

* Adding new college events.
* Viewing available events.
* Registering students for selected events.
* Viewing student registration records.
* Providing a simple menu-based interface for users.
* Storing event and registration information using Python data structures.

The current version is a basic Python console-based application. Advanced features such as online payment, email notifications, database connectivity, and online access are not included in the current scope but can be added in future versions.

---

## 3. Target Users

The intended users of this system are:

* **College Event Coordinators** – to create and manage event information.
* **Faculty Members** – to monitor event and registration details.
* **Student Organizers** – to manage student participation.
* **Students** – to register for available college events.

---

## 4. High-Level Features

### 4.1 Event Management

The system allows users to:

* Add a new event.
* Enter event name.
* Enter event date.
* Enter event venue.
* View all available events.

### 4.2 Student Registration

The system allows users to:

* Select an available event.
* Enter student name.
* Enter student roll number.
* Register the student for the selected event.

### 4.3 Registration Management

The system allows users to:

* View registered students.
* View the event selected by each student.
* Display registration information in an organized format.

### 4.4 Menu-Based Interface

The system provides a simple menu through which the user can select different operations:

1. Add Event
2. View Events
3. Register Student
4. View Registrations
5. Exit
